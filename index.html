Le bon réflexe

Ne cliquez pas. Ouvrez le site officiel en saisissant vous-même son adresse dans le navigateur.

Un score bas ne prouve pas qu'un message est légitime. Les fraudeurs peuvent imiter des marques et des personnes de confiance.
Les 3 réflexes à retenir
À GARDER EN TÊTE
1
Ne cédez pas à l'urgence

Les menaces et délais très courts sont souvent utilisés pour pousser à agir vite.

2
Vérifiez par un autre canal

Contactez l'organisme via son application ou son site officiel, jamais via le lien reçu.

3
Ne transmettez aucun code

Ne partagez jamais un mot de passe, un code de validation ou les données de votre carte.

CLAIRNET est un prototype de démonstration. Il ne certifie ni l'authenticité ni la sécurité d'un message.

Comment vous protéger
GUIDE RAPIDE
01
Faites une pause

Un message qui demande une action immédiate mérite une vérification, surtout s'il parle d'argent, de compte bloqué ou de livraison.

02
Examinez l'adresse

Un logo et un nom familier ne prouvent rien. Vérifiez soigneusement le domaine et les caractères inhabituels.

03
Reprenez la main

Ouvrez l'application officielle ou saisissez vous-même l'adresse du site. N'utilisez pas les coordonnées données dans le message suspect.

04
Signalez le message

En France, les SMS indésirables ou frauduleux peuvent être signalés au 33700. Pour d'autres cas, recherchez le service officiel adapté.

Une analyse n'est jamais une garantie
IMPORTANT

Un message peut être frauduleux sans contenir les mots typiques d'une arnaque. À l'inverse, un message légitime peut employer un ton pressant. Ne vous fiez jamais uniquement au score d'un outil.
