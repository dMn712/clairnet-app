Conseils de sécurité

1. Ne cédez pas à l'urgence

Les fraudeurs cherchent souvent à vous faire agir sans réfléchir.

2. Vérifiez les liens

Un nom de marque ou un logo ne garantit pas l'authenticité d'un site.

3. Ne transmettez aucun code

Ne communiquez jamais un code bancaire ou un mot de passe à une personne qui vous contacte.

4. Contactez l'organisme directement

Utilisez son application officielle ou saisissez vous-même son adresse dans le navigateur.

À propos de CLAIRNET

Version prototype

CLAIRNET analyse localement le texte et certains indices présents dans les adresses Internet.

Aucune base de réputation en ligne ni aucun moteur externe n'est encore connecté.

Un score faible ne garantit jamais qu'un message est sûr.
